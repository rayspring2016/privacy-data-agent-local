## [v1.15.1] - 2026-11-14

### 2026-11-21 同版本修复

- 修复带手动分组的数据透视表读取时报 `Nested.from_tree() missing 1 required positional argument: 'node'`：兼容 openpyxl 的分组索引类型声明错误，完整读取分组索引，继续沿用现有透视结果脱敏及原始缓存清理流程。

### 2026-11-16 同版本修复

- 外部工号、姓名、部门、组别、邮箱、卡号等属性默认取原文件保存结果后脱敏，保留文本前导零并先参与统一人员匹配；这类外部公式不再生成隐藏快照。缺少结果或原结果报错时提示工作表坐标，批处理继续后续文件。内部业务计算公式继续保留。网页、CLI 和清单增加外部属性取值计数。

- 其余外部业务公式的精确 VLOOKUP 支持从原文件保存缓存建立本地脱敏快照，仅导入当前公式需要的键和返回值，保留函数逻辑并改为本地引用。缓存缺失或与原保存结果不一致时不推测来源；网页、批量与命令行显示本地化数量。

- 修复普通脱敏未扫描公式引用关系的问题：不启用核验模式、使用新编号时，实际查找列也与工号列同步脱敏，避免事假、病假、旷工天数的 VLOOKUP 返回 `#N/A`。

- 工资卡号、银行卡号、银行账号及收款帐号独立作为银行账户标识处理；保留薪资或核验数值时仍脱敏。
- 修复分组标题遮挡真实表头、自定义列中的已确认工号漏处理问题。
- 核验模式根据工作簿内部精确 VLOOKUP 和直接引用，同步处理查找值、查找源以及工号/卡号等公式返回值；部门和客户查找项共用相同映射。保留公式、金额及比例，仅在有引用依据的单元格或范围传播字段类型。

- 新增分析核验模式：保留业务金额、比例、系数等数值，保留 XLSX 原公式、原计算结果，使用手动计算，避免金额被编号替换后破坏核算；数值型工号、证件、电话等标识仍脱敏。缺少公式缓存时提示原表重新计算保存。网页、命令行 `--preserve-calculations` 及批量入口同步支持。
- 网页默认允许身份不明的姓名继续脱敏：已确认员工沿用统一编号，未确认姓名按出现位置生成独立 `PDA_REVIEW_` 临时编号，附不含姓名的核验清单。临时编号不进入统一人员库；工号/邮箱冲突仍拦截。命令行增加 `--allow-unverified-people`，单文件及批量处理均支持。
- 修复统一编号误报。主姓名、员工工号或员工邮箱重复且非空值一致时允许处理。
- 仅用明确的员工工号和邮箱字段建立人员关联，排除合同编号、客户邮箱等其他字段；同一记录中的身份证号支持跨表关联。
- 同一行确有字段冲突时提示工作表、行和列，避免猜测人员归属。
- 网页批量脱敏继续处理后续文件，并允许下载已处理成功的文件。
- 支持同一工作表的并排员工明细，按小表范围匹配人员，全工作簿共用统一编号。
- 按透视表自身范围处理行字段，导出时保留脱敏后的可见结果，移除透视定义及原始缓存。复杂布局若无法可靠识别，会提示调整布局后重试。
- 姓名无法唯一匹配时显示工作表、行列、候选人数及待核验原因，便于定位未登记、重名或部门不一致。
- 支持邮箱独立登记及后续补齐工号；HRBP 姓名与自身邮箱配对，不继承其他员工身份。
- 修复多级部门、姓名公式、空白占位符和人员状态字段的误判。
- 团队、部门、组别字段优先按部门识别，避免将“客户负责人团队”等列当作员工姓名。
- 客户联系人按客户上下文、系统账号按账号单独脱敏，避免误并入员工基准；未登记的员工姓名仍待核验。
- 补充 Leader、核算商务及销售经理等人员列识别；统一模式下，自定义列里的已登记姓名也按唯一身份脱敏。重复表头不再登记为员工。
- 角色列中的多人名单逐人匹配并保留各自编号，不再将整格名单当作一个员工。
- XLSX 已识别客户名称在表头、备注、批注及公式文本常量中的重复出现共用编号；客户类型、拜访指标和金额单位不再当作客户名称。表名或公式引用名称内含客户名称时提示先调整，避免泄露或破坏引用。

## [v1.15.0] - 2026-09-14

### 2026-11-14 同版本重新打包

- 新增跨月份、跨项目统一编号；界面可切换统一/新编号，命令行使用 `--consistent-ids`。
- 人员按工号/邮箱建立唯一身份；工作簿全部 sheet 先建基准，再按姓名及部门唯一关联，重名、冲突及信息不足转待核验。
- 修复工号列名识别优先级和 CSV 前导零丢失问题；邮箱匹配忽略大小写，统一库使用独占锁及原子写入。
- 纳入命令行文件夹批处理：顺序处理 XLSX/CSV，保留部门、岗位和薪资分类选择。
- 新增 `--mapping` 导入历史映射，支持跨月份追加并沿用编号。
- 新增逐文件状态与字段选项记录；单文件失败继续处理，其批次退出码为1。
- 内部版本常量与项目声明统一为 `1.15.0`。


### 新增功能

- **薪资可选脱敏**：新增 `anonymize_salary` 开关（默认启用），支持整列薪资/薪酬数据不脱敏，使用体验与部门脱敏保持一致；Web UI 与 CLI 同步接入
- **薪资子组拆分**：将 `SALARY` 细化为 `SalaryGroup`（个人薪酬、社保公积金、人工成本、津贴、佣金、绩效奖金），支持精细化放行
- **本地成本/人效聚合**：新增 `aggregate` 命令与 Web UI「成本聚合」标签页，支持基于 k-匿名的本地成本/编制聚合统计
- **批处理收发箱**：新增 `pda_inbox/` 与 `pda_outbox/` 监听处理流程（`process_inbox.sh`）
- **公共文本接口**：提取 `text_anonymizer.py` 作为纯文本脱敏入口

### 优化与修复

- 优化内嵌人名扫描器算法，将贪婪最长匹配改为最短优先，修复“历史”的“史”被误判为姓氏等误报问题
- 在 `local_manifest.json` 中完整留痕脱敏开关参数状态
