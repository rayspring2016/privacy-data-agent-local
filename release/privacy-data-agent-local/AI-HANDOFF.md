# Privacy Data Agent AI Handoff

## Purpose

This project is a local-first data anonymization tool for HR and sales/business spreadsheets. Raw sensitive values must stay on the user's machine. Anonymized files and model-facing reports should contain only opaque local tokens.

## Current Sensitive Column Rules

Column detection is header-based in `src/privacy_data_agent/detectors.py`.

- Person fields are anonymized when headers include terms such as `姓名`, `员工`, `人员`, `负责人`, `责任人`, `联系人`, `对接人`, `销售负责人`, `客户经理`, or when the header ends with `人`.
- Non-person metric headers containing `人数`, `人均`, `人次`, `人工`, `人效`, or `人天` are excluded from the `XX人` rule.
- Organization fields are anonymized as department-like entities when headers include `部门`, `组织`, `中心`, `组别`, `小组`, `团队`, `事业部`, `大区`, or `区域`.
- Customer/company fields are anonymized when headers include `客户`, `客户名称`, `公司`, `公司名称`, `企业`, `企业名称`, `单位`, `单位名称`, `商户`, or `供应商`.
- ID, phone, and email are detected by both column headers and cell patterns.

## Token Policy

Anonymized output uses opaque random tokens generated by `src/privacy_data_agent/anonymizer.py`.

- Token format: `PDA_<16 uppercase hex chars>`, for example `PDA_A1B2C3D4E5F60708`.
- Tokens are random per run, not sequential.
- Tokens do not reveal whether the original value was a person, department, customer, phone, email, or ID number.
- The mapping file still stores `entity_type`, `token`, and `original` so local restore can work.
- `mapping.local.json` and `mapping_table.csv` contain raw sensitive values and must remain local.

## Web UI Startup

Streamlit startup is configured to avoid the onboarding email prompt and hide the Deploy toolbar button.

- `.streamlit/config.toml` sets `browser.gatherUsageStats = false` and `client.toolbarMode = "viewer"`.
- `mac/03-launch-web-ui-mac.command` and `windows/03-launch-web-ui-windows.bat` also pass `--browser.gatherUsageStats false --client.toolbarMode viewer`.
