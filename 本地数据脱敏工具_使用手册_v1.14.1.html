// 使用手册 · 2026

本地数据脱敏工具
使用手册

专为HR数据处理场景设计。帮助你在对外发送员工数据前，快速、安全地隐藏姓名、手机号、身份证号等隐私信息，全程本地处理，数据不离开你的电脑。

v1.14.1 全程本地处理 支持 Excel / Word / PDF 可逆脱敏
// 01 · 工具介绍

这个工具是干什么的？

三分钟了解工具的核心价值和使用场景。

用一句话说清楚

当你需要把员工名单、薪酬表、花名册等包含隐私信息的文件发给外部顾问、猎头、审计公司时，先用这个工具把敏感信息"替换"成无意义的代码，发出去的文件安全，还原时再还原回来。

典型使用场景

📤 外发数据前脱敏
发给猎头、薪酬咨询顾问、外部审计时，先脱敏再发送，保护员工隐私。
📊 数据分析无风险
把脱敏数据发给数据团队做分析，分析结果出来后再还原，整个过程合规。
📋 报告还原真实数据
外部做完的分析报告（Word/PPT/HTML）可以反脱敏，变回有真实数据的版本。

工作流程一览

💡
核心逻辑：脱敏 → 分析 → 反脱敏
脱敏时工具会生成一个「匹配文件」，记录真实信息和代码的对应关系（比如"张三 ↔ EMP_001"）。
反脱敏时上传这个匹配文件，就能把报告中的代码换回真实信息。
匹配文件要自己保管好，丢了就无法还原。
// 02 · 安全说明

你的数据安全吗？

这是大家最关心的问题，答案是：完全安全。

✅ 数据不上传到服务器
文件只在你的电脑本地处理。工具没有后端服务器，处理完文件就销毁，不会被任何人看到。
✅ 不调用任何 AI 大模型
所有识别和替换完全靠本地规则引擎完成，不连接 ChatGPT、Claude 等任何外部 AI 服务。
✅ 无需网络即可使用
断网状态下也能正常运行。只有首次加载字体时需要网络，核心功能完全离线。
✅ 匹配文件可加密保护
如果匹配文件也需要加密传输，可以生成密钥对其加密，对方解密时需要输入同一密钥。
⚠️
匹配文件请妥善保管
下载的 mapping.local.json 文件是还原数据的唯一钥匙。一旦丢失，脱敏数据将无法还原。建议存放在内部共享盘或有备份的位置，不要随脱敏文件一起发给外部。

// 04 · 数据脱敏

数据脱敏操作指南

按照以下步骤，5分钟内完成数据脱敏。

1
选择需要脱敏的文件
点击上传区域，或直接把文件拖进去。支持单文件，也支持一次选多个文件批量处理。

支持的格式：
.xlsx（Excel） .csv .numbers（Mac） .et（WPS） .docx（Word） .pdf
批量处理技巧： 如果有多个月份的花名册，可以一次选多个文件一起上传，工具会把它们的脱敏结果汇总到同一个匹配文件里，方便统一管理。
2
预览数据概览（可选，推荐新手使用）
上传文件后，点击「📊 预览数据概览与实体分布」，可以看到工具识别出了哪些列、准备怎么处理，处理前可以提前检查。
📊
预览表格中各列的含义
列名：文件中的列标题
实体类型：识别出的隐私类型（如"姓名"、"手机号"）
处理方式：脱敏 整列替换为代码 / 仅高置信扫描 只替换格式确定的值 / 保留 不处理
示例值：该列第一个非空值，帮你核对识别是否正确
⚠️ Word (.docx) 和 PDF 格式目前不支持预览，可以直接处理。
3
配置处理选项（可选）
大多数情况下保持默认即可。以下场景需要展开对应选项调整：

📎 同一批次追加文件
如果上个月已经脱敏过，这个月想沿用同一套代码（比如"张三"上次叫 EMP_001，这次还叫 EMP_001），可以把上次的 mapping.local.json 上传进来作为"种子文件"。

适用场景 月度花名册更新、跨文件统一脱敏
🔐 加密匹配文件
点击「生成加密密钥」，工具会生成一串随机密钥，用它加密匹配文件。反脱敏时需要输入同一密钥才能解锁。

注意 密钥只在当前会话保存，关闭页面后消失，一定要复制或截图保存，再通过安全渠道告知对方。
🎛️ 字段脱敏范围
脱敏岗位名称 / 职位 / 职务 v1.14.0 新增
默认不脱敏岗位，方便按岗位分析数据。如果要隐藏岗位信息，打开这个开关。

脱敏部门名称：默认脱敏部门。如果需要保留部门名称做分析，关掉这个开关。
📋 表格格式配置
如果你的表格第一行不是列标题，而是大标题（比如「2025年度员工统计表」），需要在这里调整表头所在行。

  • 自动检测（默认）：工具自动判断，通常准确
  • 第一行：列标题在第 1 行（最常见）
  • 第二行：列标题在第 2 行（第 1 行是大标题）
  • 自定义行号：手动输入表头所在行号
4
点击「开始处理」，然后下载结果
点击「开始处理」按钮后，工具会自动完成脱敏。处理完成后，你会看到下载区域。

⬇️ 一键打包下载（推荐）
下载一个 ZIP 包，里面包含：
  • 脱敏后的数据文件
  • 匹配文件 (mapping.local.json)
  • 匹配表格 (mapping_table.csv)
  • 使用说明文档
📁 单独下载各文件
展开「单独下载各文件」，可以分别下载脱敏文件、匹配文件，按需取用。
📌
关于匹配文件的保管规则
① 发给外部顾问时：只发脱敏后的数据文件，不要附上匹配文件
② 自己留存时：把匹配文件放在内部共享盘，与脱敏文件分开保管
③ 反脱敏时：上传脱敏后的报告 + 匹配文件，还原真实数据
// 05 · 报告反脱敏

如何还原脱敏数据？

外部顾问做完分析报告后，用这个功能把报告中的代码换回真实信息。

✅
反脱敏支持的报告格式
.xlsx（Excel） .docx（Word） .pptx（PPT） .html .md .txt

反脱敏操作步骤

1
切换到「报告反脱敏」标签页
点击工具顶部的「报告反脱敏」标签。
2
上传需要还原的报告文件
把外部顾问返回的分析报告（含脱敏代码的版本）上传进来。支持 Excel、Word、PPT、HTML、Markdown、TXT 格式。
3
上传匹配文件
上传之前脱敏时保存的 mapping.local.json 或 mapping_table.csv。

如果当时选择了加密，还需要在下方输入解密密钥。
4
点击「开始恢复」，下载还原结果
处理完成后，下载还原后的文件。报告中所有代码会被替换为真实的姓名、手机号等信息。

// 08 · 高级功能

进阶使用技巧

熟悉基本操作后，这些功能帮你处理更复杂的场景。

批量处理多个文件

同时选择多个文件上传，工具会逐个处理，并把所有文件的脱敏结果汇总到同一个匹配文件。处理完成后，点击「⬇️ 下载全部（打包ZIP）」一次下载所有结果。

✅
批量处理的优势
多文件共享一个匹配文件，同一个人在所有文件中会得到一致的代码。例如"张三"在花名册里叫 EMP_001，在考勤表里也叫 EMP_001，方便外部顾问跨表关联分析。

跨批次保持一致性

处理本月数据时，把上个月的 mapping.local.json 作为"种子文件"上传，新文件中出现相同的人/部门会沿用上次的代码，不会生成新的代号，方便长期追踪。

匹配文件加密传输

如果你需要把匹配文件通过邮件或内网发给同事，可以生成密钥对其加密，对方用相同密钥才能反脱敏。这样即使文件被截获，也无法还原数据。

发件方操作
  1. 展开「🔐 加密匹配文件」选项
  2. 点击「生成加密密钥」
  3. 复制密钥，通过安全渠道（当面/电话/企业微信）告知收件方
  4. 脱敏处理，下载加密后的匹配文件
  5. 把脱敏文件和加密匹配文件分开发送
收件方操作（还原报告时）
  1. 切换到「报告反脱敏」标签
  2. 上传分析报告
  3. 上传加密的匹配文件
  4. 在「解密密钥」输入框输入收到的密钥
  5. 点击「开始恢复」

深色/浅色主题切换

点击页面右上角的 🌙 按钮，可以在深色（护眼）和浅色主题之间切换，根据使用环境自由切换。

// 09 · 常见问题

常见问题解答

遇到问题先看这里，大部分疑惑都有解答。

Q工具识别出的列不对，多了或者少了怎么办？
先在「预览数据概览」里看一下识别结果。可以通过「字段脱敏范围」里的开关控制部门、岗位等字段是否脱敏。如需精细控制某一列，建议先把不需要脱敏的列从文件里删掉，处理完再补回来。
Q表格第一行是大标题（如"2025年员工信息表"），处理结果乱了怎么办？
展开「表格格式配置」，把表头设置为「第二行」。工具就会从第二行开始读取列名，第一行的大标题会被原样保留。
Q脱敏后发现同一个人对应了不同的代码，怎么回事？
通常是因为名字写法不一致（比如一处"张三"，一处"张 三"多了空格，或者全角半角不同）。工具是精确匹配，任何差异都会生成不同代码。建议脱敏前统一清理数据格式，删除多余空格。
Q匹配文件丢了，还能还原数据吗？
不行。匹配文件是还原数据的唯一依据，没有匹配文件，脱敏后的代码无法还原。请务必把匹配文件备份到安全的地方（如内网共享盘）。如果文件已丢失，只能重新对原始数据进行脱敏，生成新的匹配文件。
Q加密密钥忘记保存了怎么办？
密钥关闭页面后不会保存，一旦丢失就无法解密匹配文件。遇到这种情况，唯一的办法是重新对原始数据做一次脱敏（不加密），生成新的未加密匹配文件，然后重新做反脱敏。
Q可以批量处理整个文件夹里的所有表格吗？
支持批量，但需要手动选择文件，不能直接选文件夹。上传时用 Ctrl/Command + 点击多选，或把要处理的文件都拖入上传区域，就会自动批量处理，所有文件的匹配结果会汇总在一起。
Q岗位名称为什么默认不脱敏？
因为岗位是分析时常用的分组维度，保留岗位让外部顾问可以按岗位做薪酬对标、结构分析。如果不需要外部看到岗位信息，在「字段脱敏范围」里手动开启「脱敏岗位名称 / 职位 / 职务」即可（v1.14.0 新增功能）。
Q处理大文件（几万行）需要多久？
处理速度取决于电脑性能。通常几千行的 Excel 在几秒内完成，几万行在一分钟内完成。如果页面长时间没有响应，刷新重试即可，不会有数据丢失风险。
Q为什么要两个匹配文件（mapping.local.json 和 mapping_table.csv）？
两个文件内容相同，格式不同。mapping.local.json 是工具反脱敏时使用的标准格式，支持加密；mapping_table.csv 是 Excel 可以直接打开查看的格式，方便人工核查对应关系。反脱敏时用 JSON 文件，平时查阅用 CSV 文件。
